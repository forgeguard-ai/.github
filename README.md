# forgeguard-ai/.github

Organization-wide defaults for [ForgeGuard AI](https://forgeguard.ai) repositories.

- `profile/README.md` is the organization's public profile on GitHub.
- `SECURITY.md`, `CONTRIBUTING.md` and `SUPPORT.md` apply to every repository in the
  organization that does not have its own copy of the file. A repository's own file always
  takes precedence.
