## ForgeGuard AI

An independent engineering lab for local AI: model-serving infrastructure, agent systems, and
practical open-source tools for running AI on hardware you control.

**Website and documentation:** [forgeguard.ai](https://forgeguard.ai)

### Original projects

| Project | What it is |
|---|---|
| [kokoro-server](https://github.com/forgeguard-ai/kokoro-server) | OpenAI-compatible local speech synthesis for container and Kubernetes deployments. |
| [faster-whisper-server](https://github.com/forgeguard-ai/faster-whisper-server) | OpenAI-compatible local speech recognition with operationally safe container deployment. |

### Maintained forks

Forks we keep current with their upstream and change only where a change is documented.

| Project | What it is |
|---|---|
| [hermes-agent](https://github.com/forgeguard-ai/hermes-agent) | A distribution of the Hermes self-improving AI agent, as versioned container images and desktop installers. |
| [markdown-live-preview](https://github.com/forgeguard-ai/markdown-live-preview) | A browser-only Markdown editor with live preview, packaged as a self-hostable container and Helm chart. |
| [ComfyUI](https://github.com/forgeguard-ai/ComfyUI) | A hardened, telemetry-free ComfyUI with built-in authentication and HTTPS. |
| [ComfyUI-Manager](https://github.com/forgeguard-ai/ComfyUI-Manager) | ComfyUI-Manager with share and cloud integrations removed and validated, token-aware model downloads. |

Each repository carries its own license, security policy, and documentation.
